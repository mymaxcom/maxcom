MAXCOM R2, Windows install guide

Install MAX Kiosk Server on a Windows PC

This guide is for musalla volunteers. MAX Kiosk Server is the same MAXCOM box software on Windows and on Android; on Windows the folder and the Start menu entry are still named MAXCOM. Time needed: about 20 minutes.

The installer and its console speak Malay. Its messages and answers are given below exactly as they appear, with the English meaning in brackets the first time.

1. What you need

  • A Windows 10 or 11 PC (64-bit), 4 GB of RAM, 32 GB of free space.
  • A TV or monitor for the musalla screen.
  • The musalla Wi-Fi or cable network.
  • A Windows administrator account (you will be asked to press Yes once).

2. Download

The usual way is the .exe file. The .zip file is another way (see the end of section 3).

  1. Download MAX-Kiosk-Server-Setup-<version>-windows.exe from the MAXCOM site (mymaxcom.my). A .sha256 file with the same name sits beside it.
  2. Check that the file is not damaged or changed. Open PowerShell in the Downloads folder and run: 
    Get-FileHash .\MAX-Kiosk-Server-Setup-<version>-windows.exe -Algorithm SHA256
    Compare the Hash code it prints with the code in the .sha256 file or the one published on the site. The two must be the same. If they differ, do not run the file; download it again.

3. Install

  1. Double-click the .exe file.
  2. Windows asks Do you want to allow this app to make changes to your device? (UAC). Press Yes. The installer needs administrator rights.
  3. The installer is not signed yet, so Windows SmartScreen may show Windows protected your PC. Press Maklumat lanjut (More info), then Jalankan juga (Run anyway). This step is needed only because the installer is not signed yet; go on only if the SHA-256 code from section 2 matched.
  4. Follow the installer windows (all in Malay). If an older MAXCOM box is on this PC, pick its data folder on the first page; if not, leave it empty and press Seterusnya (Next), then Pasang (Install).
  5. A console window opens. Answer the three questions in it:
    • Nama pendek surau (short musalla name): the name of your musalla.
    • The address of this PC on the musalla network: if there is more than one address, pick its number. Pick the address of the musalla Wi-Fi or cable network.
    • Jenis skrin (screen type): khas (a dedicated PC for the TV, the screen starts by itself), kongsi (a shared PC, the screen is opened from the Start menu only) or tiada (no screen).
  6. Wait. Each step prints one line that starts with OK. If there is a line GAGAL: (failed), read the reason, fix it, then run the .exe file again. The musalla data is not removed. Do not close the console window until it is done.
  7. The install is complete when you see Pemasangan MAX Kiosk Server selesai. (MAX Kiosk Server installation complete) followed by Alamat kotak: (box address) and the location of the root certificate file. The installer copies its temporary files to a special folder under C:\ProgramData that only administrators can open, and removes them when it finishes.

Another way: the zip file

If the .exe cannot be used on your PC, download MAX-Kiosk-Server-Setup-<version>-windows.zip and check its SHA-256 code the same way. Right-click the zip file, choose Properties, tick Unblock, press OK. Right-click again and choose Extract All. Open the new folder, right-click Pasang MAXCOM (Install MAXCOM), choose Run as administrator and press Yes. The questions and steps after that are the same as numbers 5 to 7 above.

Installing again with the same answers is safe: steps that are already done print as OK ... sudah siap (already done).

4. Enrol the first phone

Scan the QR code on the screen with the MAXCOM app. On a phone or iPad that does not trust the box yet, first install the root certificate file named on the line Fail sijil akar (root certificate file).

5. Settings to make once

Each of these settings is the musalla's choice. They are all made on the PC or the router, not by MAXCOM.

  1. Fixed IP address: on the musalla router, always give this PC the same address (DHCP reservation). If the address changes, phones cannot connect and the box certificate has to be made again.
  2. BIOS: set the PC to power on again when the electricity comes back (an option such as AC Power Recovery or Restore on AC Power Loss).
  3. Automatic sign-in for a dedicated PC: use an ordinary Windows account without administrator rights, just for the screen. Open netplwiz or use the Microsoft Autologon tool. Anyone who switches the PC on lands in that account, so that account must not have administrator rights. The MAXCOM box itself starts before anyone signs in.
  4. Windows Update active hours: set them outside prayer times so that the PC does not restart during the azan.

6. Semak MAXCOM (Check MAXCOM)

Open the Start menu, the MAXCOM folder, and choose Semak MAXCOM. It only reads; it changes nothing. Use it after installing, after the PC restarts, or when there is a problem.

  • An OK line means that check passed.
  • A GAGAL: line means something is wrong; the text after it says what.
  • A LANGKAU (skipped) line means that check was not run (for example the screen is not in khas mode).
  • The last line Semak MAXCOM: semua semakan yang dijalankan lulus. (all checks that ran passed) means everything is fine.

7. If there is a problem

  • Blank screen: run Semak MAXCOM. From the Start menu, open Skrin MAXCOM (MAXCOM screen). In khas mode, sign out and sign in again.
  • Phones cannot connect: the PC address has probably changed. Run Semak MAXCOM and look at the health_https line; set a fixed IP address (section 5, number 1), then run Pasang MAXCOM again and pick the right address.
  • The live broadcast does not reach the TV: look at the fw_webrtc, fw_srt and tools lines in Semak MAXCOM.
  • If it still fails, write to admin@mymaxcom.my and include the GAGAL: lines you see.

8. Moving from an older box that was run by hand

Only for a musalla that already has a MAXCOM box run from a developer folder. Run Pasang MAXCOM with the option -MigrateFrom <old data folder>. The script shows the old box's processes and asks for permission before stopping them. The old folder is not changed. Do not start the old box again while this installed box is running.

9. Remove MAXCOM

Start menu, MAXCOM folder, Buang MAXCOM (Remove MAXCOM). The software, its tasks and its firewall rules are removed. The musalla data is kept: the line KEKAL: data surau di ... (kept: musalla data in ...) shows where it is (usually C:\ProgramData\MAXCOM\data), together with the backup copies in C:\ProgramData\MAXCOM\backups. The MAXCOM root certificate is also kept, so phones do not need to enrol again. The data is removed only if you run it with -RemoveData and type BUANG DATA when asked.
