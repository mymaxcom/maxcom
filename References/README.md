## Bahasa Melayu

ringkas; butiran lanjut ada di sini. Setiap panduan ada dalam tiga bahasa (BM, English, العربية), sebagai PDF yang sesuai
dicetak dan sebagai halaman HTML yang boleh dibuka dalam pelayar.

## English

This folder holds technical references for administrators and technical users. The MAXCOM landing page is kept simple
on purpose; the details live here. Every guide comes in three languages (Malay, English, Arabic), as a print-ready PDF
and as an HTML page you can open in a browser.

| File | What it is | For whom |
|---|---|---|
| `panduan-ios.pdf` and `panduan-ios.html` | One-page guide to installing the MAXCOM profile on an iPhone or iPad (Malay). | Musalla administrators, iPhone/iPad users |
| `ios-guide.pdf` and `ios-guide.html` | The same guide in English. | Musalla administrators, iPhone/iPad users |
| `ios-guide-ar.pdf` and `ios-guide-ar.html` | The same guide in Arabic. | Musalla administrators, iPhone/iPad users |
| `tema/panduan-tema.pdf` and `tema/panduan-tema.html` | Guide to making your own theme (Malay). | Administrators, theme designers |
| `tema/theme-guide.pdf` and `tema/theme-guide.html` | Guide to making your own theme (English). | Administrators, theme designers |
| `tema/theme-guide-ar.pdf` and `tema/theme-guide-ar.html` | Guide to making your own theme (Arabic). | Administrators, theme designers |
| `tema/hijau-siti.maxtheme` | Sample theme you can upload from the app and use as a starting point for a new one. | Administrators, theme designers |
| `kamera/panduan-kamera-luaran.pdf` and `.html` | Setting up an external IP camera and its sound for live broadcasts (Malay). | Musalla committee members |
| `kamera/external-camera-guide.pdf` and `.html` | The external camera guide in English. | Musalla committee members |
| `kamera/external-camera-guide-ar.pdf` and `.html` | The external camera guide in Arabic. | Musalla committee members |
| `windows/panduan-pasang-windows.pdf` and `.html` | Installing MAX Kiosk Server on a Windows PC (Malay). | Musalla volunteers |
| `windows/windows-install-guide.pdf` and `.html` | The Windows install guide in English. | Musalla volunteers |
| `windows/windows-install-guide-ar.pdf` and `.html` | The Windows install guide in Arabic. | Musalla volunteers |
