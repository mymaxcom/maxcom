# MAXCOM References / Rujukan MAXCOM

## Bahasa Malaysia

Folder ini mengandungi rujukan teknikal untuk pentadbir dan pengguna teknikal. Laman utama MAXCOM sengaja dikekalkan
ringkas; butiran lanjut ada di sini. Panduan pentadbir dan pintasan akan ditambah dari semasa ke semasa.

| Fail | Kegunaan | Untuk siapa |
|---|---|---|
| `panduan-ios.pdf` | Panduan satu halaman (BM dan English) untuk memasang profil MAXCOM pada iPhone atau iPad. Sesuai dicetak. | Pentadbir surau, pengguna iPhone/iPad |
| `tema/panduan-tema.pdf` dan `tema/panduan-tema.html` | Panduan membuat tema sendiri (BM). | Pentadbir, pereka tema |
| `tema/theme-guide.pdf` dan `tema/theme-guide.html` | Panduan membuat tema sendiri (English). | Pentadbir, pereka tema |
| `tema/hijau-siti.maxtheme` | Contoh tema yang boleh dimuat naik melalui aplikasi dan dijadikan asas tema baharu. | Pentadbir, pereka tema |

Panduan tema mengikut MAXCOM 2026.11.11.

## English

This folder holds technical references for administrators and technical users. The MAXCOM landing page is kept simple
on purpose; the details live here. Admin guides and shortcuts will be added over time.

| File | What it is | For whom |
|---|---|---|
| `panduan-ios.pdf` | One-page guide (Malay and English) to installing the MAXCOM profile on an iPhone or iPad. Print-ready. | Musalla administrators, iPhone/iPad users |
| `tema/panduan-tema.pdf` and `tema/panduan-tema.html` | Guide to making your own theme (Malay). | Administrators, theme designers |
| `tema/theme-guide.pdf` and `tema/theme-guide.html` | Guide to making your own theme (English). | Administrators, theme designers |
| `tema/hijau-siti.maxtheme` | Sample theme you can upload from the app and use as a starting point for a new one. | Administrators, theme designers |

The theme guides match MAXCOM 2026.11.11.
